Información sobre cookies

Qué tecnologías utiliza actualmente esta web y cómo puedes controlarlas.

Responsable del sitio

Steven Alberto Ramirez Paredes, persona física, titular del sitio bajo el nombre comercial NGT — Next Generation Tour. Consultas relacionadas con esta política: info@nextgenerationtour.es.

Cookies propias

En el código publicado de esta web no se han configurado cookies propias de publicidad ni herramientas de analítica de seguimiento. Las funciones principales de navegación se realizan sin necesitar cookies publicitarias.

Servicios de terceros

Las fuentes de Google Fonts, el alojamiento de GitHub Pages y el proveedor externo FormSubmit pueden realizar conexiones y tratar datos técnicos. FormSubmit puede recurrir a mecanismos antispam al enviar el formulario. Si accedes a WhatsApp, se aplicarán las tecnologías y políticas de esa plataforma.

Control desde el navegador

Puedes revisar, bloquear o eliminar cookies y datos de sitios desde la configuración de tu navegador. Bloquear funciones técnicas de un servicio externo podría impedir que algunas herramientas, como el formulario, funcionen correctamente.

Cambios futuros

Si NGT incorpora analítica, publicidad, vídeos incrustados o cookies no necesarias, este documento y los mecanismos de elección deberán actualizarse antes de activarlas. Las consultas pueden enviarse a info@nextgenerationtour.es.
